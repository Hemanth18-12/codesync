Use the Built-in Chat

Discuss your code without leaving the editor. Press Ctrl+K to toggle the chat panel. It supports Markdown code blocks and auto-linkified URLs.

  • ✅ Typing indicator with dots animation
  • ✅ Code blocks with syntax highlighting

Step 8

Run Your Code

Hit Ctrl+Enter or the Run button to execute JavaScript directly in the browser sandbox. Results appear instantly in the console below the editor.

  • ✅ Sandboxed iframe for safe execution
  • ✅ Full console.log / error / warn support
  • ✅ Execution time shown in milliseconds
  • ✅ REPL-style input for quick testing
