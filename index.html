Workspaces & Rooms

Everything in CodeSync happens inside a "Room". You can create a new room from your dashboard, which will generate a unique 6-digit code (e.g., A7B29X). Share this code with your teammates so they can join your session instantly.

Create or Join to start.

The Editor Engine

Our editor is powered by Monaco, the same engine behind VS Code. It supports syntax highlighting for multiple languages, automatic indentation, and standard keyboard shortcuts (like Ctrl+Z). Change the language using the dropdown in the top right.

Collaboration & Chat

When others join your room, their avatars will appear in the top bar. You will see their cursors moving in real-time within the editor. Use the built-in chat panel on the right side to communicate without leaving the context of your code.

Running JavaScript

If your room is set to JavaScript, you can execute the code directly in your browser. Click the "Run" button in the header (or press Ctrl+Enter). The console panel will slide up from the bottom showing any console.log() outputs or runtime errors.
